\section{Dataset}
\label{sec:dataset}

\subsection{Data Source}

For this study, we used the \textbf{STRAMPN Histopathological Images for Ovarian Cancer Prediction} dataset from IEEE DataPort. It can be found at:

\begin{center}
\url{https://ieee-dataport.org/documents/strampn-histopathological-images-ovarian-cancer-prediction}
\end{center}

The dataset contains histopathological JPEG images of ovarian tissue, labeled as either \emph{Ovarian Cancer} or \emph{Ovarian Non-Cancer}. We downloaded the data in May 2026. To respect the original authors' rights and the IEEE DataPort terms, we don't include the raw images in this repository; they have to be downloaded directly from the source.

\subsection{Class Distribution}

There are 987 images in total. As shown in Table~\ref{tab:class-composition}, the dataset is pretty well-balanced.

Since the split between cancer and non-cancer images is almost 50/50, we don't have to worry too much about class imbalance bias. This makes accuracy a useful metric for us, though we still focused on AUC-ROC as our primary measurement.

\subsection{Splitting the Data}

We split the dataset into training, validation, and test sets using a two-stage process. First, we took 75\% of the images from each class for our training and validation pool, leaving 25\% for the final test set. Then, we split that 75\% pool again, using 70\% for actual training and 30\% for validation.

We used \texttt{sklearn}'s \texttt{train\_test\_split} with \texttt{stratify=labels} to make sure the class proportions stayed the same in every subset. We also fixed the \texttt{random\_state} to 42 so that our splits are completely reproducible. The final counts for each split are in Table~\ref{tab:split}.

\begin{table}[H]
  \centering

By keeping the seed at 42, we ensured that every one of our 72 training runs used the exact same images for training and testing.
