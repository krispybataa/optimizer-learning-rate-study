\subsection{Normalization}

We applied \textbf{samplewise standard normalization} to every image using Keras's \texttt{ImageDataGenerator}. This involved:
\begin{itemize}
  \item Centering each image by subtracting its mean pixel value.
  \item Standardizing each image by dividing by its standard deviation.
\end{itemize}

We chose samplewise normalization because it's safer for small datasets like ours. Instead of relying on global statistics (which can be noisy or lead to data leakage), each image is processed independently. This makes our evaluation more reliable and ensures the model handles new images correctly during testing.

\subsection{Data Augmentation}

To help our models learn more robust features and avoid overfitting, we used data augmentation, but \textbf{only for the training set}. We kept the validation and test sets in their original state (except for normalization) to ensure our results reflect real-world performance.

Table~\ref{tab:augmentation} summarizes the augmentations we used. We picked these to simulate the typical variations found in histology slides, such as different rotations and slight scaling differences.

\subsection{Ensuring Experimental Integrity}

A key part of our methodology was ensuring that the data generators were only initialized \textbf{once} at the start of the entire 72-run simulation. If we had recreated the generators inside the training loop, each model would have seen the training images in a different order, adding "luck of the draw" as a hidden factor in our results. By sharing the same generators, we ensured that every architecture and optimizer was tested on the exact same sequence of data.
