## Project Overview

This study systematically evaluates **84 deep learning model configurations** for binary
classification of ovarian cancer from histopathological images (cancer / no_cancer).

The experiment matrix is:

| Dimension | Options | Count |
|-----------|---------|------:|
| Base architectures | VGG19, EfficientNetB3, ResNet50, DenseNet121 | 4 |
| Optimizers | Adam, Adagrad, Adamax, AdaDelta, SGD, RMSProp, <TBD> | 7 |
| Learning rates | 0.0001, 0.00001, 0.000001 | 3 |
| **Total runs** | 4 × 7 × 3 | **84** |

**Fixed hyperparameters:** dropout (0.6 / 0.4 / 0.3), dense nodes (256 / 128 / 64),
epochs 50, input 256×256, batch size 32.

**Dataset:** STRAMPN Histopathological Images for Ovarian Cancer Prediction — 987 images.

## Dataset Setup

1. Download the **STRAMPN Histopathological Images for Ovarian Cancer Prediction**
   dataset from its source repository (e.g., Kaggle).
2. Extract the archive so that images are organised into class subfolders:
   ```
   dataset/raw/
   ├── cancer/
   │   └── *.jpg  (or *.png)
   └── no_cancer/
       └── *.jpg  (or *.png)
   ```
3. Run the preprocessing script to split and resize all images:
   ```bash
   python src/preprocessing.py
   ```
   This will populate `dataset/processed/train/`, `val/`, and `test/`.

> **Note:** `dataset/raw/` and `dataset/processed/` are excluded from version control
> via `.gitignore`. Do **not** commit raw images to the repository.

---

## Running the Full Experiment

```bash
# Install dependencies
pip install -r requirements.txt

# Preprocess the dataset (run once)
python src/preprocessing.py

# Launch all 84 simulation runs
python src/run_all.py
```

Results will be written to the `results/` directory and summary figures to `results/summary/`.
